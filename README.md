# Full-Stack User Authentication System (No-Framework SPA)

Проектът представлява сигурна система за регистрация, вход и управление на потребителски профили. Изграден е като **Single Page Application (SPA)** на чист TypeScript, без използването на външни уеб фреймуърци (като Express, React и др.) и без автоматично генериран код.

---

## 🚀 Функционалности
* **Custom Web Server:** Чист Node.js HTTP сървър за API маршрути и статично съдържание.
* **Сигурна регистрация и вход:** Валидация на данните (имейл, имена, парола) и сесии чрез **JWT (JSON Web Tokens)**.
* **Релационна база данни:** Пълна интеграция с **PostgreSQL** за сигурно съхранение на потребителите.
* **Защита на паролите:** Криптографско хеширане чрез **Bcrypt**.
* **Собствена текстова CAPTCHA:** Математически уравнения, изписани с думи, защитени с краткотрайни JWT токени против ботове.
* **Управление на профила:** Защитена страница за обновяване на имена и парола с Bearer Authorization хедъри.
* **Високо тестово покритие:** Над **93% покритие на функциите** чрез Vitest.

---

## 🛠️ Технологичен стек
* **Backend:** Node.js, TypeScript

## ⚙️ Инсталация и конфигуриране

### 1. Клониране на проекта и инсталация на зависимостите
```bash
npm install
```

### 2. Конфигуриране на средата (.env)
Създайте файл с име .env в главната папка на проекта и попълнете вашите данни за PostgreSQL:
```bash
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=test1234
DB_NAME=user_auth_db
PORT=3000
JWT_SECRET=my_super_secret_key_123!
```
⚠️ Забележка: Преди да стартирате приложението, се уверете, че базата данни с име user_auth_db вече съществува във вашия PostgreSQL сървър. Приложението само ще създаде нужните таблици (Users) при първото стартиране чрез initDatabase().

## 🏃 Скриптове за стартиране
Приложението се компилира и стартира изключително лесно чрез предварително конфигурираните npm скриптове:

### 🛠️ 1. Компилиране на проекта (Build)
Компилира бекенда и пакетнира фронтенда чрез esbuild в папка dist/:
```bash
npm run build
```

### 🚀 2. Сървър (Start)
Преди стартиране е задължително да сте пуснали npm run build:

```bash
npm run start
```
След стартиране отворете браузъра си на адреса показан в конзолата.
(Ако използвате предложените настроики на .env адреса ще бъде http://localhost:3000) 

### 🧪 3. Изпълнение на Unit тестове (Test)
Стартира Vitest и генерира подробен репорт за покритието на кода (Coverage > 93% на функциите):

```bash
npm run test
```
### 📂 Структура на проекта
backend/src/server.ts – Входна точка на HTTP сървъра.

backend/src/router.ts – Маршрутизатор за API заявките и статичните файлове.

backend/src/config/db.ts – Връзка и инициализация на PostgreSQL.

backend/src/repositories/ – Data Access Layer (чисти SQL заявки).

backend/src/controllers/ – Бизнес логика (Auth, Users, Captcha).

backend/src/utils/ – Помощни инструменти (JWT Middleware, Валидация, Body Parser).

backend/tests/ – Папка с автоматизирани unit тестове.

frontend/src/app.ts – Главен TypeScript файл, управляващ Single Page интерфейса (SPA) на клиента.

frontend/public/ – Статични ресурси (HTML, CSS, компилиран JS).
